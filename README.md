## Projects

### ロボコン

学生ロボコンのチーム活動で、CADを使った機械設計や、Gitを使った設計データの管理に取り組んできました。チームで一つのロボットを作る経験を、ソフトウェア開発にもつなげていきたいと考えています。

### サークル内ナレッジ検索 / ROBOSTEP GPT

サークル内に蓄積された資料を探しやすくするため、RAGを活用した検索システムを開発しています。必要な情報にたどり着けること、回答の根拠を確認できることを大切にしています。
